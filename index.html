Import a resource pack to start

Blocks, models and block states are read from the resource packs you provide. Nothing is uploaded; the compiled result is cached in this browser.

Click: place · Right click or Eraser (E): remove · Alt+click: pick · Drag: rotate · Right drag: pan · Wheel: zoom · 1-9: hotbar · Axis ball: 2D views, then [ ] moves the plane

Share this model

Packs the model together with the models and textures of the blocks it uses, so the other side does not need your resource packs. Copy the code, or send the file when the code is too long for a message.

The code contains the textures of the blocks that are used. Only share what you may share.

Open a shared model

A shared model brings its own resources. They are added to this browser as a pack called "… (shared)" and used; your own packs stay as they are.

Settings

Language

Block names

English names and block ids are always searched too, so "stone", "Stone" and the name in this language all find the block. The names come from the language files of your resource packs.

Model space

1 to 64 blocks per side. Blocks outside a smaller space are removed. Very large spaces can be slow.

Resource packs

Everything stays in your browser. Packs higher in the list override packs below them, like in Minecraft, so put a default or vanilla pack at the bottom and special packs (for example redstone visualisation) above it.
